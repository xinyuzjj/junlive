# JunLive v1.3.4

手机版界面重做，安卓全屏这回真的能用了。

---

## 📱 手机版界面按手机 App 的规范重做

之前那套界面是从电脑版缩窄来的，看着不像手机 App。这次按手机的使用习惯逐项改：

- **底部导航加上文字**：原来只有 4 个图标，没有标签，既分不清谁是谁，看着也像少了一项。现在是「图标 + 文字」——首页 / 关注 / 分类 / 我的。
- **封面改成 16:9**：原来写死 110px 高，卡片一宽封面就被压扁，不同屏宽下高度也不跟着变。
- **标题改两行、字号 14px**：手机上一张卡只有 176px 宽，一行装不下几个字，截断后基本看不出在播什么。
- **卡片加了按压反馈**：点下去会轻微缩放，不再像在点网页。
- **右上角深色开关归位**：原来比搜索框高 4px、底色也不一样，像一块独立的白方块贴在角上。
- **平台圆点的兜底色**：个别平台没配颜色时圆点是透明的，几个 tab 长得不一样。

## ⛶ 全屏（安卓）

**系统状态栏和导航栏不再露出来。** 安卓这边的窗口全屏在底层是空实现（只打一条警告），所以之前全屏后屏幕边缘那圈系统栏一直在。这次补了一层原生实现，进全屏即隐藏；从屏幕边缘滑一下，系统栏会临时浮出来，松手自动缩回，不会让人困在没返回手势的黑屏里。

**点全屏自动转横屏。** 以前点了全屏画面还是竖的，只能一直提示你自己转手机。现在点下去直接转过去，那句提示作为兜底保留——真转过来它自己就消失了。正反两种握持方向都认。

退出全屏或退出房间都会恢复，不会让整个 App 卡在横屏。

## 🪟 桌面端

桌面端的全屏行为没有变化。

## 📦 下载

- **Windows**：`.msi`（推荐）或 `.exe`
- **macOS**：`.dmg`（Apple Silicon / Intel）
- **Linux**：`.deb` / `.rpm` / `.AppImage`
- **Android**：`.apk`（只能侧载安装）

> 如果你已经装了 v1.3.1 或更高版本，**可以直接在应用内更新**：设置页 → 软件更新 → 检查更新。

有问题请提 [issue](https://github.com/xinyuzjj/junlive/issues)。
