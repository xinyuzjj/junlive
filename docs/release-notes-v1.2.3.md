# JunLive v1.2.3

四项修复：斗鱼不再卡顿、油管不再把回放当直播、缓冲按平台区分、安装包不再缺文件。

---

## 🐛 斗鱼每 5 分钟卡一下

**原因**：斗鱼直链每 300 秒被 CDN 切断，必须续流。旧实现等断了才去解析地址、建连接，这 1.8 秒播放器收不到任何数据。

**修复**：提前 8 秒建连并预缓冲；允许关键帧小幅回退（播放器本身落后 6~12 秒，重叠落在还没播到的区间，不会重复播放）。

**实测**：空档 1799ms → **309ms**，380 秒播放进度全程连续。

---

## 🐛 油管：不在直播就不播回放

**原因**：后端用 `isLiveContent` 判断，而这个字段的含义是「曾经是直播」，下播后永远为真；前端 iframe 还用路由里的视频 ID 拼地址、且无条件渲染。

**修复**：改读 `isLiveNow`；不在直播时再查一次该频道当前有没有在播；前端只在直播时渲染，并用后端解析后的视频 ID。

**实测**：未开播 → 0 个 iframe +「该主播当前未开播」；关注里存的旧视频 ID 会自动跳到频道当前这一场。

---

## ⚡ 缓冲按平台区分

上一版为修 Twitch / 斗鱼的卡顿把缓冲调大，但写成了全局配置，其他平台白等几秒到几十秒。现在按需分开：

| 平台 | 缓冲 |
|---|---|
| 斗鱼 | 6~12 秒（每 300 秒续流，需要） |
| Twitch / SOOP | 8~60 秒（走代理，延迟抖动大） |
| 虎牙 | 1~3 秒 |
| B站 / 抖音 | 3~15 秒 |

---

## 🔧 安装包装完起不来

**原因**：GNU 工具链下 exe 动态依赖 `WebView2Loader.dll`，Tauri 的 NSIS 打包器没把它打进去（MSI 带了）。

**修复**：把 DLL 固定进项目并声明为打包资源。实测装完能正常启动。

---

## 📦 下载

| 平台 | 文件 |
|---|---|
| Windows | `-setup.exe`（推荐）或 `.msi` |
| macOS | `.dmg`（M 芯片选 aarch64，Intel 选 x64） |
| Linux | `.AppImage` / `.deb` / `.rpm` |
| Android | `.apk`（arm64，未签名，仅侧载） |

**安装提示**：用 `setup.exe`，别用 MSI（MSI 装同版本必须先卸载）。装过旧版时安装器会问要不要先卸载，选卸载它自己完成；想直接覆盖用 `setup.exe /UPDATE`。安装器未签名，SmartScreen 提示点「更多信息」→「仍要运行」。
