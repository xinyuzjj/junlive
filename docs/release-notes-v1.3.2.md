# JunLive v1.3.2

修 v1.3.1 里一个显示错误，另外让应用内的「更新说明」显示真正的内容。

---

## 🐛 版本号一直显示 v1.2.4

**问题**：设置页和关于页的版本号是**写死**在代码里的（`const VERSION = "1.2.4"`），从 v1.2.5 开始每次升版本都没人记得同步它。结果你装的明明是 1.3.1，界面却显示「已是最新版本（v1.2.4）」——看起来像更新功能坏了。

**修复**：不再硬编码，改成向程序自己查真实版本号（读的是打包时写进程序的版本，永远不会对不上）。

---

## 🐛 应用内的「更新说明」显示的是通用文案

**问题**：更新清单 `latest.json` 是构建时生成的，那时它只能拿到一段写死的通用介绍，所以应用里点「下载更新」看到的说明和这个版本无关。

**修复**：构建完成后把本版本的发布说明写回 `latest.json`，应用里就能看到真正的内容了。

---

## 📦 下载

- **Windows**：`.msi`（推荐）或 `.exe`
- **macOS**：`.dmg`（Apple Silicon / Intel）
- **Linux**：`.deb` / `.rpm` / `.AppImage`
- **Android**：`.apk`（免签名，只能侧载安装）

> 如果你已经装了 v1.3.1，**这一版可以直接在应用内自动更新**：设置页 → 软件更新 → 检查更新。

有问题请提 [issue](https://github.com/xinyuzjj/junlive/issues)。
