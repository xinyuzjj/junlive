# JunLive v1.3.3

修一个看回放时的小问题。

---

## 🐛 看回放时混进了直播弹幕

**现象**：正在看某个主播的录播，这时主播开播了，直播的弹幕会飘到录播画面上、也会混进右侧弹幕列表。

**原因**：直播弹幕的监听从进入房间起就一直挂着，看回放时也没停；而它和回放弹幕写的是同一个列表。所以直播一开播，两个来源就混在一起了。

**修复**：回放模式下丢弃直播弹幕，只显示这一场录播自己的弹幕。进入和退出回放时都会清空列表，不会残留上一场的。

## 📦 下载

- **Windows**：`.msi`（推荐）或 `.exe`
- **macOS**：`.dmg`（Apple Silicon / Intel）
- **Linux**：`.deb` / `.rpm` / `.AppImage`
- **Android**：`.apk`（免签名，只能侧载安装）
