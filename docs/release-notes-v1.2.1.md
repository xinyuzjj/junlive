# JunLive v1.2.1

**Twitch 播放重构 —— 彻底移除官方播放器，自建流加清晰度上限。**

---

## 🎮 Twitch 改动（本次重点）

### ① 移除官方播放器

之前 Twitch 有两种播放方式，现在**只剩自建流**。

**移除原因**（实测确认，不是猜测）：

Twitch 的官方播放器会校验 `parent` 参数必须与**顶层页面的真实 host** 一致。而 Tauri 打包后顶层是 `tauri.localhost`，即使 `parent` 传 `localhost` 也对不上 —— 表现是 iframe 建好了但里面 0 条网络请求，Twitch 侧显示「player.twitch.tv 拒绝连接」。

**为什么难发现**：开发模式恰好跑在 `localhost:1420`，host 完全对得上，**所以本地怎么测都正常，只有打包安装后才坏**。

也尝试过用 `tauri-plugin-localhost` 把窗口改到 `localhost`（实测确实能让 Twitch 官方播放器加载），但它会替换整个应用的 origin，连带影响 localStorage 隔离和其它平台，得不偿失。

**结论**：Twitch 走自建流。请求由 Rust 发出、能读代理设置、画质能到 1080p、弹幕与画质选择器都是我们自己的。

界面上相关的切换入口一并移除：设置页的「Twitch 播放方式」卡片、移动端播放页「更多」里的切换项。

### ② 清晰度选择器（新增）

之前 Twitch **根本无法选择清晰度** —— 画质按钮只在「多线路平台」时才显示，而 Twitch 只有一条线路，所以按钮根本不出现。清晰度由 hls.js 的 ABR 自动切换，用户只能看着它变。

现在播放器控制栏多了一个清晰度按钮：

```
⇅ 720p  ▾
   自动（不设上限）
   1080p  6882k
   720p   3600k  上限  ← 选中
   480p   1400k
   360p    800k
```

**选中的档位是「上限」而不是「锁死」**，这点很关键：

| | 锁死某一档 | 上限（现在的做法） |
|---|---|---|
| 带宽够 | 720p | 720p |
| 带宽不够 | 反复重试同一大分片 → **一直缓冲** | 自动降到 480p → **流畅** |

上限模式下 ABR 仍可在该档以下自由选择，带宽不足时降档而不是卡住。

### ③ 不再锁最高画质

之前 `lockLevel()` 会强制锁到 ≤1080p 的最高档。已去掉，现在默认完全交给 ABR 按带宽判断 —— 强行拉 1080p 时，Twitch 走代理的大码率分片更容易把缓冲抽干。

### ④ 缓冲策略加大

直播是持续的小分片请求，代理链路只要有一次延迟尖峰就会抽干缓冲。实测本地代理节点延迟在 **84ms ~ 1891ms** 之间抖动。

| 参数 | 改前 | 改后 |
|---|---|---|
| `lowLatencyMode` | `true` | **移除**（低延迟模式靠减小缓冲换延迟，抗抖动差） |
| `maxBufferLength` | 15 | **60** |
| `maxMaxBufferLength` | 30 | **120** |
| `liveSyncDurationCount` | 3 | **8** |
| `fragLoadingMaxRetry` | 6 | **10** |

代价是进房间后起播稍慢、直播延迟多十几秒 —— 换取不卡顿。

### ⑤ 视频编码限定为 H.264

请求 Twitch 播放列表时去掉了 `av1`：

```
supported_codecs=av1,h264  →  supported_codecs=h264
```

Twitch 会优先返回 AV1 流，而 WebView2 对 AV1 解码支持很差。

## 💡 关于 Twitch 卡顿

如果仍然出现「缓冲中」，那基本是**代理节点**的问题而非客户端 —— 本项目能做的已经做完。可以尝试：

1. 换用延迟更稳定的节点
2. 换协议（Hysteria2 / TUIC 等基于 UDP 的通常抖动更小）
3. 开启代理软件的 TUN 模式，减少一层封装
4. 用清晰度上限选 720p，减小单分片体积

## ⚠️ 已知限制

- **APK 未签名** —— 只能侧载，不能上架应用商店
- **iOS 暂不出包** —— 需要 Mac 构建环境与开发者账号
- **Twitch usher token 约 1 小时过期** —— 长时间观看需重新进入房间
- **720p 的码率由 Twitch 上游决定**，客户端只能设「不超过该档」，无法提高指定档的码率
- **安卓全屏时系统状态栏仍会显示** —— 属 Tauri 能力边界，详见代码注释
