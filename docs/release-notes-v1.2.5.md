# JunLive v1.2.5

**新增直播回放**（斗鱼），另修了 issue #2 里新反馈的抖音分类问题。

---

## ✨ 直播回放（斗鱼）

斗鱼直播间右上角新增「回放」按钮，能看这个主播的历史直播录像。

- **整场列表**：一场直播 = 一条记录，显示整场时长（如 13 小时 13 分），不再按 2 小时一段重复出现
- **按日期/页码定位**：一个主播可能有几千场（实测 2237 场），支持「跳到日期」（二分查找定位）和「跳到第 N 页」
- **播放器单独做的**：进度条可拖、倍速（0.5x~2x）、音量、全屏、键盘快捷键（空格/←→/↑↓/M/F）
- **历史弹幕**：按视频进度飘出来，可调字号、不透明度、速度、显示区域；拖动进度条不会补飘一堆
- **AI 看点**：自动分段摘要，点一下直接跳到对应位置
- **清晰度**：高清1080P60 / 高清720P / 标清480P，切换时保持当前进度
- **分段**：一场直播被切成若干 2 小时的段，可直接选第几段，播完自动接下一段

回放地址是让官方页面自己算签名后抓出来的（签名不过期，同一视频二次播放 0 秒起播），再用自己的播放器播放，界面里没有任何第三方页面元素。

## 🐛 抖音游戏版块是死数据

**原因**：分类 ID 里没带节点的 `type`，请求房间列表时 `partition_type` 恒传 1。而「游戏」是 `type=4` —— 类型对不上，接口返回的是完全不相干的内容。

**修复**：分类 ID 带上 type（`4_103` 而不是 `103`），请求时原样回传 `partition_type`。

**实测**：游戏、射击游戏、绝地求生、守望先锋、和平精英全部返回真实主播。

抖音把「吃鸡」「守望先锋」放在第三层（游戏 → 射击游戏 → 绝地求生/守望先锋），以前只支持两级点不到，现在会多出一行三级分类。

## ✨ 斗鱼录播直播间标记

斗鱼有些直播间其实在放录像（视频轮播），但状态显示在直播。这类房间现在在关注栏用**黄色点**标出来，和真直播区分开。

## 🐛 回放分片返回 0 字节

**原因**：代理判断「是不是 m3u8 播放列表」时，兜底逻辑只看 URL 里有没有 `playlist` —— 而斗鱼回放的分片文件名就叫 `playlist_0.ts`，被误判成播放列表逐行重写，分片返回 0 字节，播放器一直转圈。

**修复**：先排掉 `.ts` / `.m4s` / `.mp4` / `.aac` 等明确的分片后缀，再走 URL 兜底。
