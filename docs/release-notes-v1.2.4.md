# JunLive v1.2.4

三项修复，都来自 issue #2 的反馈：返回不再跳回平台首页、斗鱼的展开分类不再卡死、抖音有真实分类了。

---

## 🐛 看完直播点返回，跳回平台首页

**原因**：`App.vue` 给 router-view 绑了 `:key="$route.fullPath"`，每次路由变化都把页面销毁重建。从直播间返回时首页被重建，版块状态被重置成第一个分类 —— 所以「返回」等于回平台首页，想看同版块的其他主播得重新点一遍。

**修复**：把每个平台当前浏览的版块存进 store，重建后恢复。PC 和移动端都改了。

**实测**：斗鱼/哔哩哔哩/虎牙/抖音四个平台走完整流程（选版块 → 进直播间 → 返回），版块全部保持在原地。

---

## 🐛 斗鱼点「展开」，满屏分类、点了没反应

**原因**：斗鱼有 **540 个**顶级分类。展开后全部铺开，而分类区是 `flex:none`、外层 `overflow:hidden` —— 整块撑到 1200px 高，房间列表被顶出可视区且没法滚动。点分类其实生效了，但列表不收、结果在屏幕外，看着就是「点了没用、卡死」。

**修复**：展开时限高 `42vh` 并可滚动；选中分类后自动收起。

**实测**：展开后分类区 361px（限高可滚），房间列表仍在屏内；点分类 → 正确跳转 + 自动收起。

---

## 🐛 抖音：推荐全是重复的、游戏版块没有分类

**重复的原因**：实测抖音第 1/2/3 页返回**完全相同的 15 条** —— `offset` 参数被接口忽略，追加就是一堆重复。

**没分类的原因**：分类是写死的 6 个顶级项、子分类全空。

**修复**：
- 分类改为从抖音首页内嵌的分类树解析（首页结构变了会退回硬编码，不会空着）
- 追加房间时按房间号去重；一条新的都没有就标记到底，按钮变「没有更多了」

**实测**：抖音「游戏」下出现 `射击游戏 / 竞技游戏 / 单机游戏 / 棋牌游戏 / 休闲益智 / 角色扮演 / 策略卡牌`；点「加载更多」重复 0 条，之后按钮自动变「没有更多了」。

## 📦 下载

| 平台 | 文件 |
|---|---|
| Windows | `-setup.exe`（推荐）或 `.msi` |
| macOS | `.dmg`（M 芯片选 aarch64，Intel 选 x64） |
| Linux | `.AppImage` / `.deb` / `.rpm` |
| Android | `.apk`（arm64，未签名，仅侧载） |

**安装提示**：用 `setup.exe`，别用 MSI（MSI 装同版本必须先卸载）。装过旧版时安装器会问要不要先卸载，选卸载它自己完成；想直接覆盖用 `setup.exe /UPDATE`。安装器未签名，SmartScreen 提示点「更多信息」→「仍要运行」。
