# JunLive v1.1.1

**移动端补齐 —— 7 项优化一次性到位。**

上一版（v1.1.0）把移动端拆成了独立的一套界面，但很多东西还没做。这一版把「手机上该有的」补齐。

---

## 📱 移动端新增

### 播放页手势
手机上最顺手的操作方式，斗鱼 / 虎牙 / B站 / Twitch 手机端都是这套：

| 手势 | 作用 |
|---|---|
| **左半屏上下滑** | 亮度 |
| **右半屏上下滑** | 音量 |
| **横滑** | 进度（直播会提示「不支持拖动」） |

滑动时画面中央显示浮层提示（图标 + 百分比），松手 1 秒后自动消失。

> ⚠️ **亮度是模拟的**，用 CSS `filter: brightness()` 作用在画面上，**不是系统亮度**。桌面端会直接跳过这个手势 —— 真机要调系统亮度需要额外的原生插件，这一版刻意没引。

### 全屏重做（按手机习惯）
- **锁横屏**：进全屏自动转横屏，画面更足
- **转屏提示**：系统锁了旋转时，浮一层「📱↻ 横过来看」的动画提示
- **沉浸式**：退出按钮 3 秒后自动淡出、不挡画面，点屏幕任意位置恢复
- **横屏铺满**：横屏时播放器铺满整屏，**弹幕跟着铺满**（不再只占中间一小条）

### 首页
- **骨架屏**：加载时显示 6 个占位卡（16:9 + 标题条 + shimmer 动画），不再白屏
- **下拉刷新**：阻尼手感，三态文案（下拉刷新 / 松手刷新 / 刷新中…）

### 关注页（独立移动版）
- 单列 60px 大行：圆形头像 + 主播名 + 平台 + 在线状态点
- **左滑删除**（带确认，横向位移需大于纵向 1.5 倍，防误触滚动）
- 导出 / 导入与 PC 版**共用同一份数据**，两端互通

### 发现页（新）
底部标签栏从 3 项变 4 项（发现 / 首页 / 关注 / 设置）。「发现」是平台总览：大卡片列出全部七个平台，点一下切过去。

### 深色模式
顶栏 ☀️/🌙 一键切换，立即生效、刷新后保持。品牌色保持不变。

## ⚡ 性能：封面缩略图

移动端不再拉原始封面图。实测各平台尺寸规格，**能安全缩小的才缩**：

| 平台 | 流量降幅 | 做法 |
|---|---|---|
| 虎牙 | **-89%** | `?x-oss-process=image/resize,w_400` |
| YouTube | **-87%** | `mqdefault.jpg` |
| Twitch | -34% | `-640x360` → `-400x225` |
| 哔哩哔哩 | -22% | 追加 `@400w_225h_1c.jpg` |
| 斗鱼 / 抖音 / SOOP | 0% | 实测找不到安全规格，**原样返回** |

斗鱼、抖音、SOOP 这三个不是漏了 —— 抖音改尺寸参数直接返回 **403**，硬拼 URL 只会让封面全裂，所以按「**宁可不变，也不裂图**」处理。

## ⚠️ 已知限制

- **Android APK 未签名** —— 只能侧载，不能上架商店，也不能覆盖正式签名版本
- **iOS 暂不出包** —— 需要 Mac + Xcode + 开发者账号，且上架审核概率极低
- **手势是纯前端实现** —— 亮度是画面滤镜不是系统亮度；音量走的是播放器音量而非系统音量
- **直播不支持拖动进度条** —— 各平台直播流本身不提供 seek 能力
