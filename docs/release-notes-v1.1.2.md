# JunLive v1.1.2

**移动端整体重做 + 一个横屏致命 bug 修复。**

---

## 🔧 关键修复

### 手机横屏会变回电脑界面
移动端的判定原来只看窗口宽度（≤820px 才算手机）。手机竖屏宽 390 没问题，**但横过来宽度变成 844，就切回了电脑那套界面** —— 顶栏、平台标签、搜索框、右侧弹幕面板全回来，看起来像「网页被横过来」。

手机不会因为旋转就变成电脑。现在改成按设备类型判定，**横竖屏都是移动端界面**。

### 点全屏不真全屏
之前点全屏只改了页面样式，没有调用系统级的全屏接口 —— 所以安卓顶部的时间、信号、电量栏一直挂着不走。

现在点全屏会：
1. **直接转成横屏**（画面更足，不再做条件判断）
2. **调用系统全屏**，隐藏安卓系统栏，真正沉浸
3. 退出全屏时自动恢复

## 📱 移动端整体重做

### 导航
底部改成四项：**首页 / 关注 / 分类 / 我的**。纯矢量图标，栏高 56px，每项触控区 98×55。分类从首页里独立出来。

### 首页
- 顶部改成**平台横滑条**（七个平台一划即换）
- 卡片：列数随屏幕宽自适应（最少两列），**封面固定 110px 高**，圆角 6px
- 卡片信息精简到四项：封面、在线人数、标题（一行）、主播名
- 一屏能看到 **10 张卡**（原来 8 张且更杂乱）

### 播放页（竖屏）
从上到下四段：
```
16:9 播放器
48px 主播条（头像 + 名字 + 在线 + 关注）
弹幕列表（占满剩余全部高度）
44px 底部操作条（弹幕开关 + 说点什么 + 更多）
```

- 画质与线路移进「更多」的底部弹层
- 手势精简为：**单击**（显隐控件）、**双击**（全屏）、**左半屏上下滑**（亮度）、**右半屏上下滑**（音量）
- 移除了横向拖动进度条的手势 —— 直播本身不支持拖动，还容易误触
- **所有按钮触控区统一放大到 44px 以上**（之前播放器控制条只有 18~31px，手指根本点不准）

### 关注页
去掉了左滑删除（容易和列表滚动抢手势），改成行末一个 44px 的图标按钮，删除有确认弹窗。

### 深色模式
从两档开关改成**三档**：跟随系统 / 浅色 / 深色。跟随系统时会实时响应系统的主题变化。

## 🐛 其他修复

- **搜索框输入后没反应** —— 参数传下去了，但从来没调用搜索接口。现在真的能搜，无结果有空状态提示
- **在线人数变成没字儿的黑块** —— 后端返回的已经是「1.2万」这种文字，前端又当数字解析一遍变成了 NaN。现在直接显示
- **刘海水滴屏安全区失效** —— 缺了一行 viewport 声明，导致所有安全边距计算全部失效
- **点「项目介绍」打不开** —— `/about` 被错误地归到了设置页，形成死循环
- **深色模式下输入框白底白字** —— 聚焦样式里写死了白色背景，改用主题变量
